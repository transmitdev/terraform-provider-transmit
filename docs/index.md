# Transmit Provider

Manage [Transmit](https://www.transmit.dev) on-call as code: responders, teams, schedules, overrides, escalation policies and heartbeats.

Create a **live** API key in Settings → API keys with the `terraform` scope preset and export it as `TRANSMIT_API_KEY`. Test keys are refused for on-call configuration because it is shared by live and test incidents.

~> **Every change turns paging off.** Transmit turns paging off for a configuration after any on-call change, from Terraform or the dashboard, and cancels pending escalation, so nobody is paged by a definition that has not been drilled. After an apply, run a drill and re-activate paging in the dashboard (On-call → Paging).

```terraform
terraform {
  required_providers {
    transmit = {
      source = "puchesjr/transmit"
    }
  }
}

# Create a live key in Settings → API keys with the "terraform" scope preset,
# then export TRANSMIT_API_KEY=tr_v2_...
provider "transmit" {}
```
